# Management-System
## Employee Task Management System

A React-based employee task management system that helps admins create, assign, and track tasks efficiently.

### Features

- Separate login access for admins and employees
- Admin dashboard for creating and assigning tasks
- Employee dashboard for viewing assigned tasks
- Task status management:
  - New
  - Active
  - Completed
  - Failed
- Employee task statistics and progress tracking
- Data persistence using browser `localStorage`
- Responsive interface built with React, Vite, and Tailwind CSS

### Demo Login

**Admin**

- Email: `admin@me.com`
- Password: `123`

**Employee**

- Email: `e@e.com`
- Password: `123`

Other employee accounts are also available in the project data.

This project currently uses local browser storage for authentication and task data. Signup, backend integration, and database support have not yet been implemented.
